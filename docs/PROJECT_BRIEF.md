# PlotLoop Speaker Review · Project Brief

## 项目名称

- 产品名：**PlotLoop Speaker Review**
- 仓库名：\`plotloop-speaker-review\`
- 中文描述：说话人校对工作台
- 一句话定位：快速、私密地把模型猜测的说话人标签变成人工确认过的结构化数据。

## 命名理由

\`PlotLoop\` 是母品牌，强调把一次性任务改造成可重复、可观察、可持续改进的工作闭环。

\`Speaker Review\` 比 \`Speaker Diarization\` 更准确：本项目不直接完成音频分离或声纹识别，而是接住上游模型的候选结果，帮助人完成最终确认。

## 目标用户

- 需要批量整理会议文字稿的个人和团队；
- 使用大模型推断参会人的知识工作者；
- 需要人工在环校验的数据与内容团队；
- 希望会议数据不离开本机的隐私敏感用户。

## 核心任务

用户看到一场会议时，可以在几秒内完成三类动作：

1. 认可模型建议并进入下一场；
2. 把候选角色改成准确人名；
3. 将低置信或串并说话人的情况保留为待核角色。

## v0.1 范围

- 导入、校验和去重 \`speaker-review v2\` JSON；
- 按时间排序展示会议；
- 编辑会议元数据与一句话特别总结；
- 编辑说话人、处理方式、置信度和判断依据；
- 人名修改时自动切换为智能替换和高置信；
- 本地常用人管理；
- 全部、待确认、低置信筛选；
- 本地草稿、复制和下载；
- 桌面三栏与移动端三视图。

## 非目标

- 不内置转写模型、LLM 或声纹模型；
- 不保存真实会议样本作为演示数据；
- 不依赖登录、数据库或服务端；
- 不承诺自动修改任意格式的 Markdown/TXT；
- 不把“模型猜测”伪装成“身份事实”。

## 后续路线

### v0.2

- JSON Schema 与导入错误定位；
- 单场撤销和变更历史；
- 校对差异统计；
- 中英文界面。

### v0.3

- 可选的文字稿写回适配器；
- 花名册模板与团队共享配置；
- PWA 离线安装。

### 探索项

- 上游声纹嵌入与候选召回；
- 同一设备、会议室和参会组合的先验记忆；
- 用已确认样本评估不同模型的准确率、校准度和成本。

声纹能力应保持为可选上游模块。工具的最终决策仍以可审计的人工确认为准。

## 发布检查

- 样例全部为虚构内容；
- 不包含真实姓名、会议名、公司名和内部角色；
- 不包含绝对路径、Cookie、Token、接口地址或本地存储快照；
- 页面在 \`file://\` 和静态服务器下均可运行；
- 核心测试通过；
- 桌面和移动端无文字遮挡；
- 远程仓库由维护者确认后再配置。
