# PlotLoop Speaker Review 0.5.0 升级说明

0.5.0 把“人工已经确认”之后的工作从 Agent 手里移回确定性程序：模型负责提出候选，人负责拍板，脚本负责校验、替换和归档。这样能减少重复消耗，也让每一次回写更快、更稳定、更容易审计。

## 零模型确认回写

- 本地工作台的“确认并回写”可以直接处理 `speaker-review v2` JSON，不再依赖大模型二次阅读。
- 回写前严格校验会议、标签、姓名和动作；未确认姓名不会误写进转写。
- 写回转写与总结后，同步更新录音索引、确认台账、处理归档和下游完成信号。
- 支持离线命令处理单个确认文件，或批量扫描 `confirmed` 目录。

## 更完整的转写兼容

- 支持 Markdown 转写以及 `Speaker N 00:00:00` 格式的纯文本转写。
- 当 ASR 在一场长录音里把同一个标签分配给不同的人时，可按时间段分别写回姓名。
- 写回时保留转写和总结的原始文件时间戳，便于继续按录音发生顺序查找。
- 兼容带纳秒精度的 UTC 时间，不再因为解析失败显示错误日期。

## 私有联系人自学习

- 用户人工改名或确认后，真实姓名自动加入本机联系人库。
- 后续会议可以直接点选已经确认过的人，减少在手机远程操作时反复输入。
- 联系人库只保存在配置的 `state_dir`，不会写入公开仓库、演示数据或 GitHub Pages。

## 升级方式

```bash
git switch main
git pull --ff-only origin main
npm test
```

在线体验仍只使用虚构数据；完整的回写和联系人沉淀能力仅在用户主动配置的本地服务模式启用。
