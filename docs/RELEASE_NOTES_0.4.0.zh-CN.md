# PlotLoop Speaker Review 0.4.0 升级说明

相较 GitHub 上的 `v0.3.3`，本地版本从“单机网页校对工具”扩展为“网页快审 + 可选录音自动化 + 飞书确认 + 本地写回”的完整链路，同时保持静态网页可以独立使用。

## 工作台升级

- 增加本地“确认并回写”，已确认批次可直接提交给本机处理程序。
- 本地任务与联系人配置使用时间戳刷新，减少缓存导致的旧批次残留。
- 在线页面和强制示例模式隐藏本地回写入口，避免访问者网页触碰 localhost。
- 提交接口改为同源路径，不开放跨站写入。

## 自动化链路

- 发现并暂存新录音，连续两次文件稳定后再进入分析。
- 对暂存副本执行受保护的热词修正，不修改链接、代码片段和原始数据。
- 调用 Codex 输出 `speaker-review v2`，并将工作、私人和不确定材料分流。
- 支持“全对”“2=姓名”“3留”“4忽略”的极简文本确认。
- 确认后保留原时间戳写回转写与总结、更新索引，并生成下游完成信号。

## 飞书体验

- 使用 Card 2.0 按会议折叠展示，一句话总结、候选人、置信度和证据集中在同一处。
- 高疑惑会议优先，第一场默认展开。
- 每张卡最多四场，大批次拆卡后编号仍连续。
- 卡片失败自动退回纯文字，确认协议不变。

## 安全与发布

- 新安装默认 `enabled=false`、`mode=shadow`、飞书 dry-run。
- 私人内容默认不进入工作群，不确定分类必须人工指定。
- 本地目录、花名册、身份、群 ID、逐字稿、状态和确认数据均位于 Git 之外。
- 新增公开仓库检查，阻止本地数据文件、备份文件、绝对用户路径和真实飞书标识进入候选提交。
- GitHub Actions 会在每个提交和 PR 上执行相同的网页、自动化与公开仓库检查。
- UTC 录音时间会按配置的 `timezone`（默认 `Asia/Shanghai`）转换后再进入工作台、文件名和索引，不再依赖运行机器时区。
